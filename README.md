# IranGram | ایران‌گرام

پیام‌رسان فارسی ایران‌گرام (نسخه در حال توسعه).

## وضعیت انتشار اندروید

- شناسه بسته: `com.iranigram.app` (پس از انتشار عمومی تغییر نکند)
- نسخه فعلی پروژه: `1.0.3` (versionCode: `4`)
- خروجی CI شامل APK آزمایشی `debug` و APK انتشارِ بدون امضا `release-unsigned` است.
- **هیچ‌کدام از این دو فایل به‌تنهایی فایل نهایی قابل بارگذاری در مایکت نیستند.** برای انتشار باید APK نسخه Release با کلید امضای اختصاصی توسعه‌دهنده ساخته شود.
- کلید امضا و رمزهای آن را خارج از مخزن نگه دارید؛ هرگز keystore یا رمز آن را در GitHub عمومی قرار ندهید.

## موانع باقی‌مانده پیش از ارسال به مایکت

1. تعیین و تأیید `targetSdkVersion` مطابق آخرین الزام رسمی مایکت و آزمایش سازگاری Android.
2. ساخت و نگهداری امن keystore و تولید APK امضاشده Release.
3. تکمیل و انتشار سیاست حریم خصوصی دقیق، با راه ارتباطی پشتیبانی معتبر.
4. رفع وابستگی بحرانی اجرای اپ به دسترسی پایدار به دامنه GitHub Pages و آزمایش از شبکه کاربران هدف.
5. آزمایش واقعی ثبت‌نام/ورود، چت دونفره، گروه، کانال، بارگذاری رسانه، داستان، تماس و دسترسی‌های میکروفون/دوربین.
6. آماده‌سازی تصاویر صفحه فروشگاه، توضیحات فارسی، رده‌بندی سنی و اطلاعات ناشر.
