# IranGram | ایران‌گرام

پیام‌رسان فارسی مستقل ایران‌گرام؛ نسخه وب و پوسته اندروید آن در حال توسعه و آزمون است.

## وضعیت فعلی اندروید

- شناسه بسته: `ir.irangram.messenger`
- نسخه کد: `1.1.6` (versionCode: `17`)
- `compileSdk: 35` و `targetSdk: 34`
- گردش‌کار GitHub Actions، کد JavaScript توکار `app.html` را با `node --check` بررسی می‌کند و APK آزمایشی و APK نسخه Release امضاشده می‌سازد.
- فایل‌ها به‌صورت Artifact در صفحه اجرای گردش‌کار نگه‌داری می‌شوند (۳۰ روز)؛ این مخزن فعلاً GitHub Release دائمی ندارد.
- نسخه وب: https://amyrmftah3-hub.github.io/iran-gram/app.html?v=1.1.6
- لینک اجرای ساخت: https://github.com/amyrmftah3-hub/iran-gram/actions/workflows/build-apk.yml

کلید امضای Android باید فقط در GitHub Actions Secrets نگه‌داری شود:
`ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`, `ANDROID_KEY_PASSWORD`.
هرگز keystore یا رمز آن را در مخزن عمومی قرار ندهید.

## وضعیت آزمون و موارد باقی‌مانده

موفقیت build و بررسی نحوی JavaScript به‌تنهایی به معنی آماده‌بودن پیام‌رسان نیست. پیش از انتشار عمومی باید این موارد با دو حساب مستقل و دست‌کم دو دستگاه واقعی آزموده و نتیجه ثبت شود:

1. ثبت‌نام، تأیید ایمیل، ورود، خروج و بازیابی حساب.
2. چت خصوصی دونفره با ارسال، دریافت و همگام‌سازی زنده پیام‌ها.
3. ساخت گروه و کانال، عضویت، نقش‌های مالک/مدیر/عضو و محدودیت ارسال.
4. کانال رسمی و عضویت خودکار کاربران جدید.
5. انتشار، مشاهده، حذف و انقضای ۲۴ ساعته استوری.
6. ارسال و دریافت عکس، ویدئو، فایل، ویس و یادداشت ویدئویی.
7. جست‌وجو، آرشیو، چت مخفی، واکنش‌ها و پیام‌های ذخیره‌شده.
8. تماس صوتی/تصویری روی شبکه‌های مختلف و مجوزهای دوربین/میکروفون.
9. تست امنیت RLS، دسترسی فایل‌ها، نشست‌ها، حریم خصوصی پروفایل و خطاهای شبکه.
10. تست نصب و به‌روزرسانی APK روی نسخه‌های پشتیبانی‌شده اندروید، همراه با سیاست حریم خصوصی و راه پشتیبانی معتبر.
